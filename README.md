<summary>✅ Filled Button</summary>

```dart
AppFilledButton(
  onPressed: () {},
  label: 'Button',
  loading: false,
),
```

| Prop          | Type          | default | required |
| ------------- | ------------- | ------- | -------- |
| onPressed     | VoidCallback? | null    | no       |
| onLongPressed | VoidCallback? | null    | no       |
| label         | string        |         | yes      |
| fullWidth     | bool          | null    | no       |
| fullWidth     | bool          | null    | no       |
| loading       | bool          | null    | no       |
